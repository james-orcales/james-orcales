
# Main

setup.Main mirrors the seed-generated source tree into the destination. A seed sweep proves
convergence, pruning, and exact rewrites. The seeded model implements the production `io.IO`
boundary.

### Reproduces Each Stream

Each configuration axis, clock epoch, IO completion size, file payload, and mutation choice has an
independent seeded stream. Snapshots retain each first value for seeds zero, one, and two.

### Seeds Payload Content

The model draws controlled dotfile, process-probe, and font content from separate streams. The
normal sweep reaches four contents for each payload independently of its selected size.

### Defers Callback Delivery

The test composition root builds `io.New_Sim(seed)`, retains its Driver, and defers every callback
member through its loop. One pump pass ends when runner work becomes visible. Separate passes
expose duplicate retirement.

### Selects A Feature Subset

Each seed selects one fixed configuration for its complete run. The corpus reaches each failure
and includes fault-free runs. Fault runs deactivate full payload and path-boundary features.
The selected fault must occur at its IO operation, and setup must submit no later IO operation.

### Selects A Fixture Subset

Each source-file and empty-directory feature has an independent seeded stream. A seed holds its
selected fixture for the complete run. The normal sweep reaches each feature as present and absent.

### Covers Each IO Fault

The corpus reaches terminal and recoverable IO sites in mirror, font-copy, process-probe, and
gitignore work. Each fault must occur. Recovery must do its required work. A terminal read or write
fault permits one cleanup close, and no terminal IO fault permits another later IO operation.

### Reaches Production Bounds

The sweep reaches the full dotfile limit and both relative-path limits. It also executes one-byte
and two-byte IO completions. The full dotfile occurs at a low rate to keep the suite below 10s.
